# 🏙️ Smart City Simulation using OpenGL

A Smart City Simulation developed in **C++ using OpenGL (GLUT)**. This project demonstrates computer graphics concepts such as animation, transformations, interactive controls, and real-time rendering in a modern smart city environment.

## ✨ Features

- 🌞 Day & Night Mode
- 🌧️ Rain Animation
- 🚗 Animated Traffic System
- 🚌 Moving Bus
- 🚘 Player-Controlled Car
- 🚦 Automatic Traffic Lights
- 🏢 Randomized Buildings
- 🌳 Trees, Flowers & Benches
- 👤 Walking Pedestrian
- ☁️ Moving Clouds
- ✈️ Flying Airplane
- 🐦 Flying Birds
- 🌊 Animated Lake with Fountain
- ⭐ Night Sky with Stars
- 🔍 Zoom In / Zoom Out
- 🖱️ Mouse & Keyboard Interaction

## 🎮 Controls

| Key | Function |
|------|----------|
| **D** | Day Mode |
| **N** | Night Mode |
| **R** | Toggle Rain |
| **C** | Start/Stop Player Car |
| **+** | Zoom In |
| **-** | Zoom Out |
| **Mouse Wheel** | Zoom In / Out |
| **ESC** | Exit |

## 🛠️ Technologies Used

- C++
- OpenGL
- GLUT (FreeGLUT)

## 📚 Computer Graphics Concepts

- 2D Transformations
- Translation
- Scaling
- Animation using Timer
- Keyboard Interaction
- Mouse Interaction
- Double Buffering
- Primitive Drawing
- Real-Time Rendering

## 🚀 How to Run

1. Install **Code::Blocks** with **MinGW**.
2. Install **GLUT**.
3. Open the project.
4. Build and Run.
